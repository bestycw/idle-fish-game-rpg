# 序章：现代牛马 → 穿越选世界 → 异世征程

> **状态：** 正式叙事流程（2026-09-29 拍板）  
> **上级架构：** [player-story-spine-design](./2026-09-29-player-story-spine-design.md)（Spine / Skin 分离）  
> **后续：** 章内文案由 **Story Gen Skill** 在 Skin 约束下生成（见 §8）

---

## 1. 一句话卖点

**你是被老板榨干的现代打工人；一次「不该发生的加班」把你扔进裂隙。在坠落前，你选定了异世界的规则——武侠、仙侠或赛博朋克——并继承一份能锚定「历史人物投影」的名册，用九宫布阵在他们身上赢下本该属于老板的仗。**

玩法仍是：布阵 × 刷装 × 抽卡招募；**序章只负责动机与世界壳**，不改 `encounterId` / 解锁表。

## 2. 流程总览（正式玩家旅程）

```text
[新档 / 清档]
    ↓
① 序章 Prologue（纯 story · 不进 CHAPTERS 或 ch0 可选）
    现代线 → 压榨 → 裂隙
    ↓
② 世界选择 World Pick（玩家必选 · 可默认仙侠一键）
    武侠 | 仙侠 | 赛博朋克  （V2+ 可扩：蒸汽、克系…）
    ↓
③ 落地说明 Arrival（story · 解释招募与卡池）
    ↓
④ 主线 Spine ch1…ch6（battle/story 不变 · Skin 随世界换皮）
    Hub 显示当前世界 overlay
    每章 clear → **平行原世界简报**（现代工位仍加班 · 同步战力/名册）→ [parallel-sync-realworld-line](./2026-09-29-parallel-sync-realworld-line.md)
    ↓
⑤ 章内 / 章间（可选）Story Gen Skill 增厚 blurb（§8）
```

| 阶段 | 进战斗？ | 改 unlock？ |
|------|----------|-------------|
| 序章 | 否 | 否 |
| 选世界 | 否 | 否（仅写 `narrative.worldPreset`） |
| ch1+ | 按节点 | 仅 Spine 表 |

## 3. 序章：语气与节奏（诙谐 · 放松）

### 3.0 定位

| 要 | 不要 |
|----|------|
| 打工人自嘲、会心一笑 | 苦情、卖惨、说教 |
| 短屏、点一下走一格（摸鱼读帖节奏） | 长篇、压迫式 BGM 文案 |
| 老板/KPI **卡通化反派** | 影射真实公司、人身攻击 |
| 穿越像「带薪换服」，不是生死离别 | 沉重遗言、家庭伦理刀 |
| 选世界像挑剧透，不是高考志愿 | 术语堆叠、世界观考卷 |

**按钮文案统一偏软：**「行吧，继续」「下一个」「看看能去哪」——少用「接受命运」类中二词。

**实现节奏：** 共 **12 屏**（约 2～3 分钟）；每屏 ≤ 4 行正文；支持右上角「跳过序章 → 直接选世界」（仅二次清档后或设置里开）。

### 3.3 幕三 · 落地 + 招募说明（P09–P10 · 分世界）

#### P09 · 落地（三选一文本）

**武侠 · 江渡驿**

> 雨夜渡口。灯笼摇三下，像在说：欢迎，但别挡道。  
> 名册烫手，封面写着：**江湖异名录（试用版）**。  
> 远处有人摆阵——盾墙。不是查健康码，是查你配不配走江湖。  
> 你：「行，至少不用先填出差申请。」

**仙侠 · 城门驿道**

> 灵气灌进来，像免费加湿器。你居然没咳。  
> **劫域命格册**自己翻了一页，第一个名字亮得有点炫耀。  
> 关隘那头：盾墙试阵。规矩写在风里——先破阵，再谈别的。  
> 你：「比周一晨会清晰。」

**赛博 · 下层检卡口**

> 酸雨 + 霓虹。义眼提示：*订阅已过期，请续费或续命。*  
> 芯片滚动：`HISTORICAL_GHOST.exe — max deploy 5`。  
> 闸机外安保列盾阵算法。**第一层防火墙**，字面意思。  
> 你：「至少故障界面比 OA 好看。」

## 4. 世界选择（构建后续情节的锚）

### 4.1 预设 id（引擎枚举）

| `worldPreset` | 显示名 | 气质关键词 |
|---------------|--------|------------|
| `wuxia` | 武侠世界 | 江湖、客栈、内力、门派、侠义 |
| `xianxia` | 仙侠世界 | 宗门、灵力、劫数、飞剑、渡劫 |
| `cyberpunk` | 赛博朋克 | 霓虹、义体、巨企、下层区、数据冥河 |

- 存档字段：`PlayerNarrativeState.worldPreset`（与 `skinPreset` 同义，实现时二选一命名）。  
- **Spine 六章不变**；仅 **NarrativeOverlay + 词表 + Hub 美术倾向** 切换。

### 4.2 统一「历史人物招募」解释（partyFrame）

三种世界共用逻辑，换比喻：

| 世界 | 名册名称 | 为何能召关羽/孙悟空/曹操… |
|------|----------|---------------------------|
| 武侠 | **江湖异名录** | 史传与话本里的「意」被裂隙吹到江湖，可结阵同行 |
| 仙侠 | **劫域命格册** | 轮回漏出的上古投影，借你阳寿一瞬显化 |
| 赛博 | **魂线档案馆** | 旧时代人类数据图腾，在暗网被编译成战斗体 |

**对玩家一句：**  
「他们不是来给你打工的——是你付得起『锚定代价』（抽卡/体力/星尘）时，愿意为你挡一刀的投影。」

与 **老板** 的对照（可选 Hub 冷笑话）：  
「以前你一个人扛 KPI；现在你可以让赵云扛线。」

## 6. 数据与状态机（实现备忘）

```typescript
type WorldPreset = 'wuxia' | 'xianxia' | 'cyberpunk';

interface PlayerNarrativeState {
  /** 序章+选世界完成 */
  onboardingPhase: 'prologue' | 'world_pick' | 'arrival' | 'mainline';
  worldPreset?: WorldPreset;
  prologueStep?: number;       // 0..6
  bibleId: string;             // official pack id 或 AI hash
  overlay: NarrativeOverlay;   // 含 ch1–ch6 显示文案
  partyFrame: string;
  worldName: string;
  /** 预留：老板线梗、玩家选的吐槽标签 */
  modernTags?: ('加班' | 'PUA' | '摸鱼')[];
}
```

- **Hub**：`onboardingPhase !== 'mainline'` 时隐藏副本网格或只亮「继续序章」。  
- **清档**：重置 narrative，重新走序章（可选「跳过序章」仅 DEBUG）。

## 8. Story Gen Skill 契约（你后续要建的 skill）

> 实现位置建议：`.cursor/skills/story-gen/SKILL.md` 或 CI 离线生成；**运行时只读缓存 overlay**。

### 8.1 Skill 职责

- **输入：** `worldPreset`、可选 `userPrompt`、`spineVersion`、可选 `chapterId`（单章增量）  
- **输出：** 通过 §5 校验的 `NarrativeOverlay` 片段  
- **禁止：** 改 encounter / unlock / 数值；禁止超长 blurb  

### 8.2 Prompt 必带上下文

```yaml
canon:
  modern_hook: 现代牛马被压榨 → 裂隙 → 已选 {{worldPreset}}
  party_frame: {{partyFrame 来自 official pack}}
  spine_chapter: {{chapterId}} nodes: {{nodeIds 列表}}
  encounter_hints: {{各 node 的 prepHint 一句}}
tone: 诙谐放松 · 打工人自嘲 · 短屏 · 第二人称「你」 · 不苦情不说教 · 老板/KPI 卡通化
```

### 8.3 建议 Skill 工作流

1. 读 `chapter/defs.ts` + 官方 pack 骨架  
2. 生成/润色 **blurb / title / place / unlockFlavor**  
3. 跑 `validateNarrativeOverlay()`  
4. 写入 `officialPacks/generated/` 或导出给前端 JSON  

### 8.4 与「自定义一句」关系

- 序章后已选世界 → 用户再写「我想更腐、更燃」→ Skill **只改 Skin**，不动世界枚举。  
- 未写 → 用该世界 official pack 全文。
