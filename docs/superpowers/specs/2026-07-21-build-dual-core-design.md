# 构筑双核愿景（人解法 × 装风格 · 2026-07-21）

> **地位：** 产品构筑与循环**愿景**（工作草案，**非战斗 §4.14 级冻结**）。  
> **可玩性基调（产品宪法）：** 见 [product.md §2.0](./product.md)——**丰富选择 + 双核凿深 + 反四不像**。本文是基调在构筑上的展开。  
> **已拍板方向：** 路线 **C · 双核正交**；单机以「刷 → 想办法过 Boss/关」为可玩性核心。  
> **权威落点：** 细节分别写入 [equipment](./systems/equipment.md) / [gacha](./systems/gacha.md) / [character](./systems/character.md) / [dungeon](./systems/dungeon.md)；技能内容 [skill-design-spec](./2026-08-02-skill-design-spec.md)；本文管总图与原则。  
> **实现门禁：** 战斗手感验收 **已通过（2026-07-21）**。按 tracking：副本结构化 → 力灵双轴 → 套装 → 抽卡。

## 0. 基调落在构筑上（防四不像）

**我们是什么：** 九宫布阵 × 刷装构筑（摸鱼文字壳）。  
**丰富从哪来：** 只深挖 **人（解法）** 与 **装（风格，含力灵双轴）** 两核的正交组合。  
**我们不是什么：** 不是「系统集邮册」——每多一个养成轴，都要能回答：它让过关多一条**可读的选择**，还是只让数字变大。

| 允许加深 | 视为四不像风险（默认拒绝） |
|----------|---------------------------|
| 双轴、套装、T3/T4、软关卡解法、升星技能质变 | 宠物+符文+羁绊墙+五行+力敏智**同时**当主循环 |
| 弱连携（可选、不锁通关） | 第三条与双核无关的「也能通关」养成主轴 |
| 后置：主属性转化进双轴 | 结果层再叠一套互不转化的主属性 |

**自检句（加任何功能前）：**  
「玩家多了一种**怎么过关**的选法，还是只多了一种**肝法**？」——后者不做或降级。

## 1. 目标与成功标准

### 1.1 玩家要感到什么

1. **丰富搭配**：人物组合、属性流派、词条/套装收集，都能改变「怎么打过去」。  
2. **不是硬战力卡**：过不去 = 缺解法、或缺风格堆叠、或关键星技能未质变——可对症去刷/去抽/去换阵。  
3. **单机刷宝乐**：每天主动玩的主爽点在掉落与重搭；抽卡提供紧张感与（上线后）付费点。

### 1.2 成功标准（设计层）

| # | 标准 |
|---|------|
| 1 | 同一难关至少 **2～3 条**合理通关路径（换装 / 换人换站位 / 升星技能 可互补） |
| 2 | 战败有一句**可读**提示，指向解法缺口或风格缺口（非「战力不足」） |
| 3 | 衣柜有囤货理由：灰套、未激活特技、图鉴亮点 |
| 4 | 付费只加速「凑齐解法位 / 星级技能质变 / 少肝」，**不买通关资格** |

## 2. 核心循环（单机）

```
进本 / 爬塔 / Boss
  → 掉落（底子 / 随机 / 条件 / 稀有 / T3 / 套装件）
  → 换装调属性 ± 必要时换人换站位 ± 升星
  → 再打
  → 过：推进；不过：提示 → 回「人」或「装」一侧补洞
```

抽卡穿插：缺职能/缺招牌技能时抽；重复卡喂升星；星尘兜底防单机卡死。

## 3. 双核分工（已拍板 · C）

| 核 | 玩家在想 | 系统 | 产出 |
|----|----------|------|------|
| **人 · 解法核** | 谁能解这个机制？站哪？技能够不够质变？ | 卡池、布阵、成长三轴中的**升星技能**、抽卡 | 职能、技能 tags/状态、站位、弱连携（可选） |
| **装 · 风格核** | 堆什么流派？条件对谁？套齐了吗？ | 装备词缀、套装、T3、T4、副本掉落分流 | 副属性人格、稀有玩法、条件乘区、套装 2/4、T4 每人 1 |

**正交约定：**

- 只换装能过一部分关（风格对上）。  
- 只换人/升星能过一部分关（解法对上）。  
- 高难关常要两边都对 —— 这才是「想办法打过去」，仍非等级墙。

### 3.1 与「成长三轨」对齐（修正旧表述）

> 旧表述把「升星」整段塞进底子轨，**低估了升星的技能质变**，与抽卡定位矛盾。以下为准。

| 轨 | 定什么 | 主要来源 |
|----|--------|----------|
| **解法轨** | **会什么**：新卡职能/技能 + **升星解锁的招牌技能/被动** | 抽卡（新人、重复卡） |
| **底子轨** | **底数多高**：等级、破境；升星里的**属性部分** | 战斗经验、爬塔修为、升星属性节点 |
| **风格轨**（原「强度轨」） | **同一阵刷出什么人格**：随机 / 条件 / 稀有 / T3 / 套 / T4 | 副本刷装 |

「强度」不再暗示纯战力数字；改称 **风格轨**，与双核「装」一致。

## 4. 装 · 风格核细则

### 4.1 词缀分层

细则认 [equipment.md](./systems/equipment.md)。

| 层 | 身份 | 例子 |
|----|------|------|
| 底子 | 厚度 | 攻防血，跟装等 |
| 随机 | 你是谁 | 暴击 / 坚韧（槽位保底） |
| 条件 | 对谁 / 哪种出手 | 对后排、技能威力 |
| 稀有 | 换玩法 | 格挡 / 吸血 / 锁息 |
| T3 | 一件事 | 噬血锋、先手结界 |
| T4 | 改技能 | 血刃、寒霜（每人 1 石） |

I / 随机 / 条件与 [combat](./systems/combat.md) 结算咬合。T3 挂进战 Buff，不新开战斗子系统。不做符文树。

### 4.2 形态石互斥

| 项 | 约定 |
|----|------|
| 范围 | T4 形态石 |
| 同时生效 | **每人 1 个** |
| 不互斥 | 底子、随机、条件、稀有、套装 2/4、T3 |

### 4.3 套装

| 件数 | 作用 |
|------|------|
| **2** | 小味，易凑，鼓励开刷 |
| **4** | 定义对症流派（破甲流 / 抗压流 / 济世流等） |
| **6** | 后置奢侈，不挡主线 |

- 掉落与本种/章节解锁绑定，见 [equipment](./systems/equipment.md) + [dungeon](./systems/dungeon.md)。  
- 战斗只消费已激活效果；定义权在装备系统。

## 5. 人 · 解法核细则

### 5.1 阵容

- 出战 ≤5；九宫站位修正保留。  
- 新卡必须补 **职能或解法缺口**，不只数值更高（与 gacha 一致）。  
- **弱连携**（同 tag / 同套件数触发小协同）为可选中后期；**禁止**强羁绊墙锁通关。

### 5.2 成长三轴（与抽卡咬合）

| 轴 | 主要来源 | 玩家感受 |
|----|----------|----------|
| 等级 | 战斗 exp | 底子慢慢厚 |
| 破境 | 爬塔修为等 | 抬等级上限 + 小跳点 |
| **升星** | **抽卡重复卡优先**；星尘兜底 | 属性 + **关键星技能/被动质变**（紧张感与付费点） |

升星节点优先挂已有钩子：`followUp` / `effects` / `applyStatus` / `focusPolicy` 等；管道见 [character-foundation](./2026-08-02-character-foundation-design.md)，内容见 [skill-design-spec](./2026-08-02-skill-design-spec.md)。

### 5.3 抽卡（付费与刺激）

详见 [gacha.md](./systems/gacha.md)。摘要：

| 产出 | 意义 |
|------|------|
| 新人物 | 解法位；紧张「来了缺的人」 |
| 重复卡 → 升星 | 招牌技能更强；付费加速流畅 |
| 星尘 | 单机防卡死；付费仍可买券加速 |

**原则：** 不氪可过主线（慢星 + 装与站位补）；氪的是少肝与更快点亮质变。

## 6. 压力层（Boss / 关卡）

敌人用 **解法需求** 施压，不用纯等级墙：

| 压力例子 | 人侧补洞 | 装侧补洞 |
|----------|----------|----------|
| 高疗 | 禁疗 / 爆发窗口技能 | 终伤、爆发堆装 |
| 高防 | 破甲技能 | 破甲特技 / 破军套 |
| 多段群攻 | 前排坦、群盾 | 格挡、均衡套 |
| 控制链 | 幸运/解控职能 | 免控一次饰品等 |

战败提示应对准上表之一。过关检查单（设计用）：

1. 提示说缺什么？  
2. **有人吗？** → 抽/换人/升星  
3. **有装吗？** → 对症本刷词条/套/特技  
4. **站位对吗？** → 布阵  

## 7. 收集元乐趣

- 词条 / 套装 / 卡图鉴（[codex](./systems/codex.md) 登记；开工后接）。  
- 灰套「差 N 件」、已激活特技在人物面板可见。  
- 同装不同人因精通味道不同（已有钩子）。

## 8. 深度包与明确不做

### 8.1 必要深度包：力·灵双轴（已拍板 · 2026-07-21）

> 权威细则：[combat.md §4.8 伤害类型](./systems/combat.md)。此处只定产品位置。

- **必要：** 丰富构筑与刷装取舍（力装 vs 灵装、打高防还是打低灵防）。  
- **气质：** 对齐仙剑手游常见攻/灵，**非**照搬 IP；显示名随故事皮。  
- **状态：** **引擎 + 面板 + 技能 school + 词缀池已落地（2026-07-21）**；副本按力/灵掉落分流可再加深。  
- **与主属性：** 双轴是**结果层**；力耐敏智若上，只能转化进双轴，不替代双轴。

### 8.2 明确不做 / 更后置

| 项 | 原因 |
|----|------|
| 宠物、完整符文库、强羁绊墙 | product：不借鉴再刷一把过重系统 |
| 连击/再动次数乘区 | 与急速模型易打架；单独评估 |
| 力耐敏智转化层 | 双轴之后再开 |
| 五灵/元素克制 | B18；不与双轴绑死 |
| 硬战力锁章、付费买通关 | 原则禁止 |
| T4 海量并行 | 每人 1 石 |

## 9. 面板演进（不推翻已拍板骨架）

[character-panel-wow-layout](./2026-07-20-character-panel-wow-layout.md) 骨架保留。愿景上中核应从「四维 + 一行副属性」演进为：

- 主属性墙（攻 / 防 / 抗 / 血 / 身法）  
- 副属性可读（暴击 / 暴伤 / 穿透 / 精通 / 坚韧 / 气运）  
- 非零稀有词  
- 已激活套装 2/4 与 **当前 T4**  

具体改版另开 UI 切片；本文不改槽位冻结。
