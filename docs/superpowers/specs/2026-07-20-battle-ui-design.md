# 战斗界面 UI（2026-07-20）

## 目标

竖版对战台：上敌下我；战报可读；九宫站位仍是主信息。

## 锁定

| 项 | 结论 |
|----|------|
| 范式 | ① 竖版对战台为主，偷一点 ② 战报短句/色层 |
| 分栏 | 宽屏战场左 + 战报右；窄屏战报改底栏 |
| 九宫朝向 | 面对面：双方前排贴中间交战线 |
| 不做 | 新单位卡重绘、飘字、特效、战报筛选 |

## 结构

```
header（回合 / 遭遇 / 自动手动）
main
  stage：敌方板 → 交战线 → 我方板 →（可选）主角操作
  log：战报侧栏 / 底栏
```

## 行序

- 敌方：后 → 中 → 前（自上而下）
- 我方：前 → 中 → 后（自上而下）
