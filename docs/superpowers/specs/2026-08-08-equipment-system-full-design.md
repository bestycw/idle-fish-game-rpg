# 装备系统完整设计（2026-08-08 · 定稿）

> **地位：** 替代 [systems/equipment.md](./systems/equipment.md) 旧规格；装·风格核的核心兑现。  
> **上位约束：** [build-dual-core-design](./2026-07-21-build-dual-core-design.md)；[attribute-system-redesign](./2026-08-08-attribute-system-redesign.md)。  
> **自检：** 装备系统每个子模块必须回答"让玩家换了怎么打"，不只是"数字变大"。

---

## 0. 总览

```
装备（绑角色，每角色独立 10 槽）
  = 基础属性（固定，按槽位+品级缩放）
  + 随机词缀（统一大池，软权重，纯数值）
  + T3 效果（随装备掉落，按槽位分池，可重铸）
  + 宝石孔（紫+ 有 0-1 孔，可替换返还旧宝石）
  + 套装归属（2/4 件效果）

强化（绑装备本身，上限 +15，便宜）
  + 继承（同槽位装备间转移等级，花少量金币）
  + 分解返还 80% 强化石

T4 形态石（独立道具，绑角色，每角色 1 个）
  来源：分解传说装备 / Boss首杀 / 极稀有掉落

连锁加成（自然涌现，不是独立系统）
  连锁1：单角色全身装备强化等级相同 → 该角色全属性 +N%
  连锁2：5 个出战角色连锁1等级相同 → 全队额外 +N%

挖矿（每日 5 次，消耗体力 6/次）
  主产：强化石
  副产：宝石（概率，气运影响）
```

## 4. 随机词缀（统一大池 + 软权重）

### 4.1 规则

- 从统一池中随机 N 条（N 由品级决定）
- **每件装备不重复同一种词缀**
- 每槽位有**偏好池（70% 权重）**+ 剩余池（30%）
- 稀有属性在此池中但权重极低（不强制出，纯运气）
- **气运只在稀有权重层**（极低概率）

### 4.2 词缀池

| 词缀 | 类型 | 范围 | 权重层 |
|------|------|------|--------|
| ATK | 主属性 | +3~12 | 高 |
| DEF | 主属性 | +3~10 | 高 |
| RES | 主属性 | +3~10 | 高 |
| HP | 主属性 | +10~40 | 高 |
| SPD | 主属性 | +1~3 | 中 |
| critRating | Rating | +4~14 | 中 |
| critDmgRating | Rating | +4~12 | 中 |
| penRating | Rating | +4~10 | 中 |
| masteryRating | Rating | +4~10 | 中 |
| tenacityRating | Rating | +4~10 | 中 |
| dodge | 稀有 | +2~6% | 低 |
| block | 稀有 | +2~6% | 低 |
| lifesteal | 稀有 | +2~5% | 低 |
| critResist | 稀有 | +2~6% | 低 |
| counter | 稀有 | +2~5% | 低 |
| echo | 稀有 | +2~5% | 低 |
| thorns | 稀有 | +2~5% | 低 |
| resilience | 稀有 | +2~4% | 极低 |
| steal | 稀有 | +2~4% | 极低 |
| fortuneRating | 稀有 | +2~6 | 极低 |

### 4.3 槽位偏好（70% 权重分配）

| 槽位 | 偏好（70%权重给这些） |
|------|---------------------|
| weapon | ATK, critRating, critDmgRating, penRating |
| offhand | DEF, RES, tenacityRating, masteryRating |
| head | HP, masteryRating, tenacityRating |
| chest | HP, DEF, RES, tenacityRating |
| hands | ATK, critRating, critDmgRating, penRating |
| feet | SPD, HP, penRating, masteryRating |
| back | RES, HP, masteryRating, tenacityRating |

### 4.4 稀有词缀出现规则（额外独立判定）

| 品级 | 概率 | 最多条数 |
|------|------|---------|
| 普通/精良 | 0% | 0 |
| 稀有(蓝) | 3% | 1 |
| 史诗(紫) | 5% | 2 |
| 传说(金) | 8% | 2 |

> 稀有词缀是**额外独立判定**，不占随机词缀的条数。也就是说紫装 = 4 条随机 + 可能额外 1-2 条稀有。

## 7. 强化系统

### 7.1 规则

| 项 | 设计 |
|----|------|
| 绑定 | **绑装备本身** |
| 上限 | +15 |
| 成功率 | 100%（无失败） |
| 消耗 | 金币 + 强化石（便宜：每级约 1-2 石） |
| 效果 | 基础属性按比例提升（每级 +5% 基础属性） |

### 7.2 消耗参考

| 等级 | 强化石 | 金币 |
|------|--------|------|
| +1~+5 | 1石/级 | 50金/级 |
| +6~+10 | 2石/级 | 100金/级 |
| +11~+15 | 3石/级 | 200金/级 |
| 总计+15 | 约 30 石 | 约 1750 金 |

### 7.3 继承

| 项 | 设计 |
|----|------|
| 操作 | 旧装备(+N) → 新装备(同槽位) |
| 效果 | 新装备变+N，旧装备变+0 |
| 消耗 | 少量金币（50） |
| 限制 | 同槽位 |

### 7.4 分解返还

| 装备强化等级 | 额外返还 |
|------------|---------|
| +0 | 只返品级基础（金币+石） |
| +N | 额外返还 N × 80% 强化石（向下取整） |

## 8. 连锁加成

### 8.1 连锁1（单角色）

| 条件 | 效果 |
|------|------|
| 该角色 10 件装备强化等级**全部相同** | 全属性 +(等级 × 1%) |

按**最低等级**算：9 件+10、1 件+8 → 连锁 Lv8。

### 8.2 连锁2（全队）

| 条件 | 效果 |
|------|------|
| 5 个出战角色的连锁1 等级**全部相同** | 全队额外 +(等级 × 0.5%) |

同样按最低算。

### 8.3 设计定位

连锁是"小菜"——简单达成后保持即可。鼓励均匀投入。不是核心策略来源。

## 13. 数据结构变更

```typescript
// shared/types.ts

export type Rarity = 'common' | 'uncommon' | 'rare' | 'epic' | 'legendary';

export type EquipSlot = 'weapon' | 'offhand' | 'head' | 'chest' | 'hands' | 'feet' | 'back' | 'neck' | 'ring' | 'trinket';

export interface Equipment {
  id: string;
  name: string;
  slot: EquipSlot;
  rarity: Rarity;
  /** 基础属性（固定，按槽位+品级） */
  baseStats: Partial<Record<'atk' | 'def' | 'res' | 'maxHp' | 'spd', number>>;
  /** 随机词缀（统一池） */
  affixes: AffixInstance[];
  /** 稀有词缀（额外独立判定） */
  rareAffixes?: AffixInstance[];
  /** T3 效果 #1 */
  effectAffixId?: string;
  /** T3 效果 #2（传说才可能） */
  effectAffixId2?: string;
  /** 套装 */
  setId?: string;
  /** 孔位 */
  socketCount: 0 | 1;
  /** 已镶宝石 */
  gemId?: string;
  /** 强化等级 */
  enhanceLevel: number;
}

// PlayerState 扩展
interface PlayerState {
  // 每角色独立装备：{ templateId: { slotId: equipmentId } }
  characterEquip?: Record<string, Partial<Record<EquipSlot, string>>>;
  // T4 形态石：{ templateId: morphId }
  characterMorphs?: Record<string, string>;
  // 挖矿
  enhanceStones?: number;
  gems?: { gemId: string; count: number }[];
  mineCountToday?: number;
  mineDay?: string;
  mineExtraLimit?: number;
  // T4 形态石背包
  morphStones?: string[];
}
```

## 15. 明确不做

- 附魔系统（T4 已覆盖）
- 装备交易/拍卖行（单机）
- 套装 6 件效果
- 强化失败/掉级
- 宝石分颜色/孔位匹配
- 装备耐久度/修理
- 品级升级（掉什么是什么）
- T3 独立道具化（保持随装备掉落）
- 共享衣柜（改为每角色独立）
