# 传说招牌剧本圣经（Legendary Signature Kit）

> **地位：** 现行切片。抬高**绝品/深做卡**单栏招牌的设计感；补强 [skill-design-spec](./2026-08-02-skill-design-spec.md) 与 [legendary-knife2](./2026-08-26-legendary-knife2-design.md) 里「赵云标准仍偏零件堆叠」的缺口。  
> **拍板：** 2026-08-29（对照「新的开始」传说技：底板即剧本、升星换玩法、软模式变招）。  
> **范围：** 先规范 + **四张示范重写**（刘备 / 赵云 / 吕布 / 周瑜）。不一次扫全库；不新开第二技能栏；不做姿态/蓄力键系统。

---

## 0. 问题与目标

**现状痛点：** 每人只有一招招牌，但 ★0 常像「造成×伤害」；升星像背包解锁（+倍率 / 解锁净化）；玩家侧文案像能力池拼盘。

**目标：**

1. **★0 已是完整招式剧本**，不是等升星才像传说。  
2. **升星改玩法或加深剧本**，不是叠无关零件。  
3. **软模式**：同一 `skillId` 随战场条件变招，逼近「新的开始」内置分支感。  
4. **典故戏感**仍守 skill-design-spec 自检（遮名能猜人）。

**非目标（本刀不做）：**

- 第二主动栏、姿态键、蓄力/二段操作层。  
- 新增状态主表 id（优先复用能力池 / 现有效果）。  
- 一次改完剩余未深做绝品。

---

## 1. ★0 招牌最低配置（绝品/深做强制）

每张深做卡的底板 `SkillDef` **必须同时具备**：

| # | 要件 | 说明 |
|---|------|------|
| 1 | 母题一句 | `motif` / 技能名 / `blurb` 能回答「这人是谁」 |
| 2 | 主效果可感知 | 约伤/约疗/约盾数字在技能页成立 |
| 3 | ≥2 条咬合零件 | 条件乘区、标记、灌气、先声、破盾、残血加疗等；**禁止**「仅 multiplier」。灌气等节奏零件可用触发率（见 [效果触发率](./2026-08-30-effect-proc-chance-design.md)），治疗/护盾仍必中 |
| 4 | 软模式槽（推荐 ★0 就有） | 至少声明 1 条「当条件成立时，本招改用效果包 B」；条件用现成战场语义 |

**咬合**定义：零件互相服务同一解法（例：流血为猎印铺垫；残血加疗服务群疗续航），不是三条无关词缀。

**验收：** 遮住卡名，只看 ★0 技能文案，能说出职能与打法；不能只剩「造成伤害」。

## 2. 软模式（Soft Mode）

### 2.1 定义

- **同一** `skillId`、同一技能栏。  
- 出手时读取战场条件，选择 **效果包 A（默认）** 或 **效果包 B（变招）**。  
- 条件白名单（可扩展，但本刀只用已有语义）：`has_status`（猎印/流血等）、`target_hp_below`、`self_hp_below`、`first_cast`、`target_has_shield`、`ally_downed`（若运行时已有等价钩子）。

### 2.2 作者写法（规范层）

每张示范卡在技能表增加（实现可落 `SkillDef` 扩展或并列 `softModes[]`，计划阶段定字段名）：

```
softMode:
  when: <条件>
  then: <effectPatches / followUp / multiplierDelta / statusPatches 之一组>
  copy: <玩家一句，如「猎印目标：斩杀加重」>
```

- 技能页：默认展示主剧本；软模式用短句挂在效果行或点词，**不**另开技能栏。  
- ★3/★6 可以**升级软模式**（放宽条件、加重 then），不得在未选分支上双线全拿互斥零件。

### 2.3 引擎边界

- 优先复用现有 `effects` / `followUp` / 条件乘区运行时。  
- 缺钩子时：只加**通用条件调度**，禁止为单卡写死 `if (id === 'zhouyu')`。  
- 姿态/蓄力/二段键 → **另开刀**，不在本文。

## 3. 升星节奏（里程碑质变）

| 星 | 职责 |
|----|------|
| ★0 | 完整剧本（§1） |
| ★1 / ★2 / ★4 / ★5 | **只打磨已有动词**（层数、门槛、气量、追击率、软模式数值） |
| ★3 | **质变**：分支换剧本或开启/切换软模式主轴（二选一） |
| ★6 | **同线高潮**：加厚 ★3 所选线，可升级软模式 |

### 3.1 数值 vs 文案

- 星章**可以**含 `a_main_pct_*` 等肉身数值（养成需要）。  
- **玩家可见终态文案禁止**只写「主属性+3%」「技能倍率+0.10」。  
- UI 必须译成招式语言（例：「龙胆更深 · 流血更久」），主属性%可进次级/工具提示，不得当星章主句。

### 3.2 与能力池关系

- 制作侧仍从能力池取原子。  
- 拼装时必须通过「咬合自检」：本星效果是否服务 ★0 母题动词。  
- 禁止星章标题用「主属性强化」「连击契机」当个性轨终态（沿用 skill-design-spec）。

## 4. 示范卡骨架（数值另表）

### 4.1 刘备 · 桃园结义（群疗）

- **★0：** 全队治疗 + 残血加疗 + 济元回能（咬合续航）。  
- **软模式：** 场上有倒地友军时，本招倾向招魂/起身（条件以现网钩子为准；没有则 ★3 济世线承担）。  
- **★3：** 济世（净化） / 护民（结界）——换辅线，不是「解锁一个词」。  
- **★6：** 同线高潮（招魂加厚 / 结界加厚）。

### 4.2 赵云 · 龙胆枪（单体破阵）

- **★0：** 穿点 + 流血 + 破盾类咬合（保持赵云标准厚度）。  
- **软模式：** 目标带猎印时，斩杀/追击加重。  
- **★3：** 突阵（追击） / 猎印（标记）。  
- **★6：** 贯阵或标靶高潮。

### 4.3 吕布 · 人中吕布（爆发）

- **★0：** 高倍率 + 先声 + 残血加伤咬合。  
- **软模式：** 自身低血时切换更狠的效果包。  
- **★3：** 连戟（追击） / 重斩（纯爆）。  
- **★6：** 同线高潮。

### 4.4 周瑜 · （群控/火计母题）

- **★0：** 群体伤害或控制轴 + ≥1 条铺场/延控咬合（具体状态用现池，不新开 id）。  
- **软模式：** 目标已受控时，伤害或延控加重。  
- **★3：** 火攻 / 水计（或等价典故二分）：一条偏伤，一条偏控。  
- **★6：** 同线高潮。

## 5. 技能页信息层次（玩家向）

招牌区只保留：

1. 约伤/约疗/约盾大数字 + 系数  
2. **当前生效剧本**（效果行，可点词）  
3. 一句 flavor  
4. **下一星**（前瞻）  
5. 星章列表（质变与打磨）

**禁止回流：** 「养成」差分汇总行；制作侧注疏；「通常×1.4」与本卡数字打架。

## 6. 落地顺序（实现另开 plan）

1. 本规范入库；与 skill-design-spec / knife2 **冲突时以本文抬高绝品门槛**（凡品/良品仍可薄）。  
2. 定 `softMode` 字段与通用调度（最小运行时）。  
3. 按 §4 重写四张示范（数据 + 文案 + 测例）。  
4. 技能页星章文案翻译规则（主属性%藏到次级）。  
5. 再开刀：其余深做卡按清单迁徙。

## 7. 验收清单

- [ ] 四张示范 ★0 均满足 §1  
- [ ] 各有至少 1 条软模式（或文档注明钩子缺口与临时挂 ★3）  
- [ ] ★3/★6 文案是换玩法，不是「解锁 XX」口吻  
- [ ] 星章主句无裸「主属性+x% / 技能倍率+0.xx」  
- [ ] 无第二技能栏、无新状态主表 id、无姿态键  
- [ ] 测例覆盖软模式触发与不触发两条路径
