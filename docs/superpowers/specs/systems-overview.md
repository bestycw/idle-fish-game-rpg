## 3. 核心循环与系统骨架

> **整体骨架 = 主循环 + 子系统分工。**  
> 开发按系统拆 plan；**战斗 §4.11 已验收**；B1–B4（抽卡/体力/副本/章节框架）已落地。  
> **系统完工标准（2026-07-29）：** 玩法闭环 + **扩展口/注册表**；做透一个系统再换下一个（见 [tech §7.2.1](./tech.md)）。  
> **当前主线：** 公版卡池本批已完成；下一系统待定。进度以 [tracking.md](./tracking.md) 为准。

### 3.1 主循环

```
推剧情章节 → 解锁更强装备池 / 活动 / 新副本
     ↓
打副本 → 刷词缀 / 套装 / 特技（装 · 风格核）
     ↓
抽卡 → 补职能 / 新解法；重复卡升星 → 技能质变；等级/破境抬底子
     ↓
九宫布阵（≤5）→ 自动战斗通关剧情与刷本（可改阵/换装重试）
     ↓
（可选付费）抽卡与升星进度、体力续航 → 更流畅，不锁通关权
```

总图愿景：[build-dual-core-design](./2026-07-21-build-dual-core-design.md)。

### 3.4 构筑双核与成长三轨（已确定 · 2026-07-21 修订）

> **总图：** [build-dual-core-design](./2026-07-21-build-dual-core-design.md)（单机刷宝 · 人解法 × 装风格）。  
> **勿与「人物面板三轴」混淆：** 面板等级·破境·升星 = 成长轴；本节「三轨」= 产品经济分工。

**双核（玩法感受）：**

| 核 | 定什么 |
|----|--------|
| **人 · 解法核** | 职能、技能解法、站位；抽卡得人；**升星技能/被动质变** |
| **装 · 风格核** | 词条三档、套装 2/4、形态特技；副本刷装 |

**三轨（经济分工 · 修订）：**

| 轨 | 系统 | 定什么 |
|----|------|--------|
| 解法轨 | 抽卡 → 新人 + **重复卡升星（技能质变）** | **会什么** |
| 底子轨 | 等级 / 破境；（升星的**属性**部分） | **底数多高** |
| **风格轨**（原「强度轨」） | 装备词缀 / 稀有 / 特技 / 套装 | **同一阵刷出什么人格** |

> **已废止：** 「升星整段只属底子轨」「强度轨 = 战力数字墙」。升星技能属解法轨；装备是风格与效率，不作硬门闸。

### 3.5 设计原则

1. **策略可过关，付费买流畅。** 非硬战力锁下一章；抽卡加速人/星，不买通关权。  
2. **软难度 + 可重试**：战败给可读反馈（指向解法或风格缺口）。  
3. **可玩性基调：** [product §2.0](./product.md)——双核丰富、反四不像；**双核 + 三轨**见 §3.4。  
4. **剧情锁内容池，不锁通关资格。**  
5. **非挂机**：主动玩才推进。  
6. **三层皮肤分离**：规则引擎 / 故事皮 / 卡面皮；战斗认 role + jobId。  
7. **系统边界清晰**：战斗只消费输入；养成与外壳后挂，钩子先留（§4.15–4.16）。  
8. **单机可玩性在刷与构筑**；参考只借一层，不集邮式叠加。

### 3.6 实现顺序（骨架级）

```
① 战斗手感验收 ✅（2026-07-21）
② 力·灵双轴 ✅（引擎+面板；副本分流可再加深）
③ 副本结构化（猎装 + 塔 / 掉落倾向）✅ B3；星尘秘境 ✅ 薄加
④ 抽卡（新人 + 重复卡升星）✅ B1；人物池扩后置
⑤ 体力 ✅ B2；摸鱼补给 ✅
⑥ 章节进度框架 ✅ B4（锁内容池；内容继续改表）
⑦ 装备：套装 2/4（+ 词条 III / 形态特技）· 等内容后置
⑧ 故事皮加深 / 真付费 / 图鉴；（更后）力耐敏智转化
```

> **进度以 [tracking.md](./tracking.md) 为准**；本文只给骨架顺序。拆 plan 时按 §3.3 / §3.7 系统名归档。

## 代码目录与系统对应

`packages/game-core/src/` 按系统拆目录；对外仍通过 `@moyu/game-core` 聚合导出，web 无需改 import。

| 系统 | 目录 | 主要符号 |
|------|------|----------|
| 共享 | `shared/` | `types`, `rng` |
| 战斗 | `combat/` | `combat`, `targeting`, `ratings`, `mastery`, `lifecycle`, `*Registry` |
| 角色 | `character/` | `SKILLS`, `UNIT_TEMPLATES`, `growth`, `createUnitFromTemplate` |
| 布阵 | `formation/` | `grid`, `DEFAULT_DEPLOYED_IDS`, `buildPlayerParty`, `placeUnit` |
| 装备 | `equipment/` | `AFFIX_DEFS`, `generateEquipment`, `equipItem` |
| 副本 | `dungeon/` | `defs`, `ENCOUNTERS`, `lootTables`, `grantDungeonReward`, `climbTower`, `runStardustRealm`, `tryClaimDaily` |
| 抽卡 | `gacha/` | `pullGacha`, 常驻池 / 软保底（池受章节解锁过滤） |
| 体力 | `stamina/` | `syncStamina`, `trySpendStamina`, `getStaminaView` |
| 章节 | `chapter/` | `CHAPTERS`, `START_UNLOCKS`, `advanceStoryNode`, `isContentUnlocked` |
| 存档 | `save/` | `createInitialPlayer`, `loadOrCreatePlayer`（`PlayerState.version` **8**） |

依赖方向：`shared` ← 各系统；`character` ← `formation` / `combat` / `dungeon` / `gacha`；`equipment` ← `formation` / `save` / `dungeon`；`combat` 不依赖 `save` / web；`stamina` ← `save` / Hub 开战前。

**Web 信息架构（定调 · 2026-07-29）：**

| 底栏 | 管什么 |
|------|--------|
| 冒险 | 战斗/刷本相关：主线、补给、猎装、塔、星尘秘境；灰锁悬赏/竞技 |
| 召唤 | 抽卡 |
| 伙伴 | 全池一览 + 养成详情 + 布阵入口 + 图鉴（灰） |
| 背包 | 装备衣柜 + 商会（灰） |

顶栏：资源 + 邮件/设置（灰）。细则见 [web-ui-foundation](./2026-07-21-web-ui-foundation.md)。  
Web：`packages/web/src/features/` — `hub` / `battle` / `gacha` / `character` / `inventory` / `result`；入口 `App.tsx`。
