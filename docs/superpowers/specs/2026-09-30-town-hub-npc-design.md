# 城镇 Hub · NPC 与交互（卷一）

> **目标：** 像常见 RPG——城镇可「进入」，街上有 **职能型 NPC**（商、驿、悬赏、见闻），不单绑单章剧情点。  
> **前期：** 交易/悬赏 **壳子**（可看界面、按钮灰显+说明），不挡主线。

## 1. 双轨 NPC

| 轨道 | 数据 | 出现条件 | 用途 |
|------|------|----------|------|
| **场景 NPC** | `volumeBeats.npcSlots` | 地图「路线图」点选 **章节场景** | 本章剧情人物、场间闲聊 |
| **城镇 NPC** | `townHub.ts` 注册表 | 城镇 `reachable` + `minChapterCleared` | 常驻职能：商、驿、悬赏、见闻 |

Spine 槽位仍只 5 个；城镇可有多名 **职能角色**（部分复用 `npc_merchant` 显示名，部分用城镇专属见闻位）。

## 2. 交互结构

```
城镇地图弹窗（单页「地图」）
├── 城镇折叠 + 场景 + 同块人物（剧情与商驿赏合并标签）
└ Tab「城镇」→ 已抵达城镇列表 → [进入]
         └── 城镇内页：NPC 卡片网格（职能角标）
                  └── 点击 → 底部抽屉：头像 / 职能 / [交谈] [职能按钮…]
```

- **商人 · 看看货单：** `TownMerchantShell`（分类 Tab，暂无实购，文案说明解锁条件）
- **驿 · 歇脚：** 壳（体力/剧情休息，后续接 stamina）
- **悬赏 · 看榜：** 壳（对接 `quest.md` / story-gen-quest）
- **见闻：** 仅交谈

## 3. 解锁（卷一）

| 城镇 | 大致开放 | 常驻职能 |
|------|----------|----------|
| 外郭 | ch1+ | 接引、驿卒见闻、货郎（货单壳 ch4 前锁定） |
| 中陆 | ch3+ | 商人、长老（悬赏壳）、驿 |
| 边庭 | ch5+ | 商人、同辈见闻、悬赏壳 |
| 要塞 | ch8+ | 商人、暗线见闻、悬赏壳 |

## 4. 非目标（本阶段）

- 自由走动小地图、多房间
- 实装商店扣款、任务接交（仅壳）
