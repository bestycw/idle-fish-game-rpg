## 边界

| 本系统负责 | 不负责 |
|------------|--------|
| 池子、保底、抽卡消耗与发放 | 升级曲线、破境材料（→ [character](./character.md)） |
| 写入持有卡；重复卡记入升星碎片 | 装备掉落（→ [equipment](./equipment.md)） |
| 付费点「抽卡券/钻石」接口 | 通关资格、章节硬锁 |

## 1. 产品定位（已拍板 · 2026-07-21）

抽卡是 **紧张感 +（上线后）主付费点**，不是唯一变强手段。

| 产出 | 玩家得到 | 双核位置 |
|------|----------|----------|
| **新人物** | 新职能 / 新技能解法 | 解法核 · 补洞 |
| **重复卡** | **升星**消耗；点亮更强技能/被动 | 解法核 · 技能质变 |
| （可选）养成材料碎片 | 少量星尘等 | 兜底，不替代重复卡主路径 |

**与刷装分工：**

- 刷装 = 单机每天主循环（风格核，免费深度）。  
- 抽卡 = 阵容身份与招牌技能爽点；付费加速流畅。  
- **不氪可过主线**（慢星 + 星尘 + 装/站位补）；禁止付费买通关权。

## 2. 池与规则（V1 落地）

| 项 | 规则 |
|----|------|
| 池 | 1 个常驻池（非主角模板） |
| 消耗 | `ticket` 抽卡券；单抽 1、十连 10 |
| 权重 | 未拥有基础权更高；**缺职能**再加权 |
| 软保底 | 连续未出新卡达 8 次 → 下一抽强制从未拥有中抽（若还有） |
| 新卡 | `owned=true`，可上阵 |
| 重复 | `cardShards +1`；升星**只扣碎片** |

开局赠券（Demo 12）；旧档迁移补券。章末解锁 `baigujing` / `medusa` / `zhuge` / `athena` 等（见 chapter/defs）。

## 3. 与升星的咬合

| 项 | 约定 |
|----|------|
| 升星消耗 | **仅同名碎片**（见 §3.1）；**禁止**星尘直接升星 |
| 星尘用途 | **兑换同名碎片**（慢补，护抽卡付费核）见 §3.2 |
| 关键星效果 | 技能/被动质变 + 属性；见 [character](./character.md) / [skill-design-spec](../2026-08-02-skill-design-spec.md) |
| 付费买什么 | 更多抽次 → 更快出人、更快叠星；**不**卖通关、**不**卖满星捷径 |

### 3.1 升星碎片消耗（加码）

| 目标星 | 同名碎片 |
|--------|----------|
| ★1 / ★2 / ★3 | 1 |
| ★4 / ★5 | 2 |
| ★6 | 3 |

满星纯碎片合计 **10**。实现：`starShardCost`。

### 3.2 星尘兑换（2026-08-02 定稿）

> 抽卡是人核与氪金主口；星尘只做慢补，日产须严控。

| 项 | 约定 |
|----|------|
| 兑换 | **200 星尘 → 1 同名碎片**（指定已拥有） |
| 日限 | **每日 1 次**指定兑换 |
| 助星上限 | 仅当该卡 **当前星 &lt; ★4** 可兑；**★5 / ★6 必须抽卡碎片** |
| 不做 | 随机未拥有匣、星尘直接升星、买通关 |

**产额目标（约日产 20～25，含日常）：**

| 来源 | 量 |
|------|-----|
| 星尘秘境 | **8～12** / 次（体力约支撑一天 2 次级） |
| 塔每 5 层 | **18** |
| 摸鱼补给 | **+6 星尘** / 日 |
| 开局赠尘 | **20**（薄） |

粗算：约 **8～10 天** 兑 1 碎片；纯尘最多助到 ★4（约 5 片路径），**无法纯尘满星**。  
实现：`stardustExchange.ts` / `STARDUST_REALM_RANGE` / `TOWER_MILESTONE_STARDUST` / `DAILY_CLAIM_STARDUST`。

## 4. 付费与经济

- 优先落地付费点：**抽卡**（角色/星进度）。  
- 月卡 / 体力：**预留接口，后置**。  
- 游戏内 `ticket` 跑通免费闭环；真支付走 adapter。  
- 上线前概率公示 → tracking B13。

## 5. 不做

- 用抽卡锁章节通关。  
- 多卡池深运营（初期）。  
- 抽装备替代刷装主循环。
