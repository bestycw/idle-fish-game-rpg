> 构筑总图见 [2026-07-21-build-dual-core-design.md](../2026-07-21-build-dual-core-design.md)（人 · 解法核）。

## 边界

| 本系统负责 | 不负责 |
|------------|--------|
| 池子、保底、抽卡消耗与发放 | 升级曲线、破境材料（→ [character](./character.md) / growth-draft） |
| 写入持有卡；重复卡记入升星碎片 | 装备掉落（→ [equipment](./equipment.md)） |
| 付费点「抽卡券/钻石」接口 | 通关资格、章节硬锁 |

## 1. 产品定位（已拍板 · 2026-07-21）

抽卡是 **紧张感 +（上线后）主付费点**，不是唯一变强手段。

| 产出 | 玩家得到 | 双核位置 |
|------|----------|----------|
| **新人物** | 新职能 / 新技能解法 | 解法核 · 补洞 |
| **重复卡** | **升星**消耗；点亮更强技能/被动 | 解法核 · 技能质变 |
| （可选）养成材料碎片 | 少量星尘等 | 兜底，不替代重复卡主路径 |

**与刷装分工：**

- 刷装 = 单机每天主循环（风格核，免费深度）。  
- 抽卡 = 阵容身份与招牌技能爽点；付费加速流畅。  
- **不氪可过主线**（慢星 + 星尘 + 装/站位补）；禁止付费买通关权。

## 2. 池与规则（V1 落地）

| 项 | 规则 |
|----|------|
| 池 | 1 个常驻池（非主角模板） |
| 消耗 | `ticket` 抽卡券；单抽 1、十连 10 |
| 权重 | 未拥有基础权更高；**缺职能**再加权 |
| 软保底 | 连续未出新卡达 8 次 → 下一抽强制从未拥有中抽（若还有） |
| 新卡 | `owned=true`，可上阵 |
| 重复 | `cardShards +1`；升星**优先扣碎片**，无碎片再扣星尘 |

开局赠券（Demo 12）；旧档迁移补券。章末解锁 `baigujing` / `medusa` / `zhuge` / `athena` 等（见 chapter/defs）。

## 3. 与升星的咬合

| 项 | 约定 |
|----|------|
| 升星优先消耗 | **同名重复卡碎片** |
| 无重复时 | `stardust` 兜底 |
| 关键星效果 | 技能/被动质变 + 属性；见 growth-draft |
| 付费买什么 | 更多抽次 → 更快出人、更快叠星；**不**直接卖通关 buff |

## 4. 付费与经济

- 优先落地付费点：**抽卡**（角色/星进度）。  
- 月卡 / 体力：**预留接口，后置**。  
- 游戏内 `ticket` 跑通免费闭环；真支付走 adapter。  
- 上线前概率公示 → tracking B13。

## 5. 不做

- 用抽卡锁章节通关。  
- 多卡池深运营（初期）。  
- 抽装备替代刷装主循环。
