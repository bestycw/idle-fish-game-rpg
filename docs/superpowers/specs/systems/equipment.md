#### 套装（本系统 · 与副本推进绑定）

> **不归战斗刀二。** 定义、掉落、解锁在本系统 + 副本；战斗仅在进战时读取已激活效果。

| 项 | 结论 |
|----|------|
| 字段 | 装备预留 `setId`（刀一已可掉落带 id） |
| 效果 | **2 件 / 4 件**；V1 **不做 6 件**老套 |
| 初版套数 | 先 **1～3 套** 验证（如破军/铁壁/济世） |
| **推进关系** | 某套的掉落池 / 高权重本，由**副本类型或章节解锁**打开；避免无进度时「乱掉全套」 |
| 开工时机 | 副本 B3 已落地（猎装 + 塔可掉 `setId`） |
| 当前 | 猎装本高 `setIdChance`；**已结算** 2/4 数值（`sets.ts`：破军/铁壁/济世）；旧 `set_demo_*` 别名兼容 |

#### 品质与词缀

- 品质：common / rare / epic（预留 legendary）。  
- 词缀：主属性 + 六副属性评级（整数，**含终伤**）；稀有两位小数。  
- 旧档：Demo **bump key，旧档作废**。  
- V1 不做符文/插槽树（≠ 禁止少量形态特技，见下）。

#### 词条三档（愿景 · 与双核对齐）

> 总图：[build-dual-core-design](../2026-07-21-build-dual-core-design.md)。本表为装备侧权威摘要。

| 档 | 名称 | 内容 | 状态 |
|----|------|------|------|
| **I** | 数值词 | 主属性 + 六副属性评级 | 已有生成 |
| **II** | 风格稀有 | 闪避 / 吸血 / 抗暴 / 格挡（两位小数） | 规格已有；掉落权重可加深 |
| **III** | 形态特技 | 改「怎么打」（附带状态、每第 N 动强化、耗能 − 等） | **愿景**；挂 `effects`/进战 Buff，不新开战斗子系统 |

**形态特技互斥：** 每人同时仅 **1** 条「攻击/行动形态」类；优先级预留：套装主动 > 武器 > 饰品。数值词与风格稀有不互斥。  
**挂钩（2026-08-02）：** `Equipment.morphId` → `equipment/morphs.ts` → `SkillModifier` → `composeSkill`；示范特技 `morph_bleed_edge`（血刃）。特技池后填。

#### 与战斗的接口

```
装备系统 derive（词缀 ± 稀有 ± 已激活套装 ± 形态特技）
        ↓
   写入 UnitRuntime / 进战短 Buff
        ↓
战斗系统只按已有数值与 status 结算（不查 set 表）
```
