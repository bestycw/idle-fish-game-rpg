# 装备系统

> 系统骨架 #4。**玩法权威在此。**  
> 套装是本系统子模块；战斗只消费已算好的数值与进战 Buff。  
> 掉落与「哪套可刷」与 [dungeon.md](./dungeon.md) / [chapter-progress.md](./chapter-progress.md) 联动。  
> 属性地基认 [attribute-system-redesign](../2026-08-08-attribute-system-redesign.md)。  
> **代码：** 生成器 / 装等 / 穿戴 / 条件 / 新 T3 / 洗练 / 封存 / 战力已按本文落地。数字可再调。

## 1. 一件装备从上到下

底子（必有生命，无区间，厚度跟装等）  
→ 随机（前半副属性保底，后半主+副全池，有区间）  
→ 条件 0～2（只加 %，有区间）  
→ 稀有 0～2（纯概率，不必出）  
→ T3 最多 1（一件小事，窄区间）  
→ 孔 → 套装

T4 是人物石，不在装备上。强化只吃底子。

| 层 | 身份 |
|----|------|
| 随机 | 你是谁 |
| 条件 | 对谁 / 哪种出手 |
| 稀有 | 换玩法 |
| T3 | 一件事 |
| 孔 | 加一条数 |
| T4 | 改技能 |

## 3. 三种等级

| | 管什么 |
|---|---|
| **装等** | 只抬**底子**。掉落跟章节走（六段，装等仍 ≤100；后两章挤在化神穿戴档 81–100） |
| **强化** | 这件底子上 +5% / 级，0～15，100% 成功 |
| **穿戴** | 破境不到穿不上；不另做角色等级墙 |

随机副属性、条件 %、稀有 % **不跟装等涨**。读条：`装等 36` 与强化 `+8` 分开。

| 破境 | 可穿装等 |
|---|---|
| 炼气 | 1–20 |
| 筑基 | 21–40 |
| 金丹 | 41–60 |
| 元婴 | 61–80 |
| 化神 | 81–100 |

## 4. 品级 droptable

品级：白 `common` / 绿 `uncommon` / 蓝 `rare` / 紫 `epic` / 金 `legendary`。显示名走故事皮词表。

| 品 | 底子倍率 | 随机 | 条件 | 稀有 | T3 | 孔 |
|---|---|---|---|---|---|---|
| 白 | ×1.0 | 无 | 无 | 无 | 无 | 无 |
| 绿 | ×1.2 | 2（1 副 + 1 全池） | 无 | 8% 第 1 | 无 | 无 |
| 蓝 | ×1.5 | 3（**2 副 + 1 全池**） | 40% 出 1 | 15% 第 1 | **无** | 无 |
| 紫 | ×1.8 | 4（2 副 + 2 全池） | 必 1，40% 第 2 | 25% 第 1 → 12% 第 2 | 40% 出 1 | 50% |
| 金 | ×2.2 | 4（2 副 + 2 全池） | 必 1，60% 第 2，可极词 | 40% 第 1 → 20% 第 2 | **必 1** | 必有 |

稀有永远概率、不必出。第二条稀有必须先有第一条再掷。绿蓝最多 1 条稀有。

掉率权重（副本可再加权）：白 40 / 绿 30 / 蓝 20 / 紫 8 / 金 2。

## 5. 底子

公式（数字后填）：白值 × 品级倍率 × f(装等)。

- 每件必有生命。手套、项链也有生命。  
- 底子**不定区间**。强化只乘底子。

---

## 6. 随机词

副属性五条：暴击、暴伤、穿透、精通、坚韧。气运不进此层，进稀有彩票。不开命中。

**前半**只从该槽小池抽（必须副属性）。**后半**从主属性（攻 / 防 / 抗 / 血 / 身法）+ 五条副属性全池抽。同件不重复。稀有不进此池。

随机层全部浮动，读条带 `[min - max]`。

## 7. 条件（10 种，只加 %）

无触发日志。可洗、可封存。金极词 ×1.5，可超普通上限。伤害类加总帽建议 35%（后填）。减伤全身取最高，帽 20%。持盾伤害、受后排减伤走自己的帽。

| 条 | 槽 | 普通区间 | 用途 |
|---|---|---|---|
| 技能威力 | 武器；饰品（奶吃治疗） | 8–14% | 第 3 回合那一发 |
| 普攻伤害 | 武器 | 6–12% | 两回合攒气 |
| 对前排 | 武器 | 10–16% | 打盾墙 |
| 对后排 | 武器 | 10–16% | 点杀；穿透打后排算后排；后排死光打前排不算 |
| 对健康 ≥80% | 武器 | 10–16% | 开场 |
| 对受伤 ≤35% | 武器 | 12–18% | 收尾 |
| 对异常 | 武器或饰品 | 10–16% | 控 / 流血 / 破甲 / 猎印 |
| 持盾时伤害 | 武器 | 8–14% | 剩余护盾都算（技能盾、T3 结界），格挡不算 |
| 受伤害减少 | 甲 / 副手；饰品也可 | 4–8% | 取最高 |
| 受后排伤害减少 | 甲 | 6–12% | 克制穿后排 |

不做常驻「+伤害」（与技能 / 普攻重复）。

## 8. 稀有（纯概率）

| 角色 | 条 |
|------|-----|
| 玩法核 | 格挡、闪避、吸血、回响、锁息 |
| 调味 | 抗暴、反击、回元（大招后 +1～2 气，全身帽 +6） |
| 彩票 | 气运 |

## 9. T3（一件小事，最多 1）

蓝不出。紫 40% 一条。金必 1。可重铸类型。不封存。

不要：又一条 +% 伤害（那是条件）；击杀大额回气（会买回合）。

相邻 = 九宫上下左右，不含斜角。场外 T3 **行动级**（这次去的人穿着才算），同名本次不叠。仓库挂件不生效。采矿需能选角色后才接探脉。

## 13. 强化 / 继承 / 连锁

绑装备本身。上限 +15。成功率 100%。效果：每级 +5% **底子**。

| 等级 | 强化石 | 金币 |
|------|--------|------|
| +1～+5 | 1 石 / 级 | 50 金 / 级 |
| +6～+10 | 2 石 / 级 | 100 金 / 级 |
| +11～+15 | 3 石 / 级 | 200 金 / 级 |

**继承：** 同槽旧件 +N → 新件变 +N，旧件变 +0；消耗少量金币。

**连锁**（小菜，均匀投入）：

| | 条件 | 效果 |
|---|---|---|
| 连锁 1 | 该角色 **12 件**强化等级全部相同 | 全属性 +(等级 × 1%) |
| 连锁 2 | 5 个出战角色的连锁 1 等级全部相同 | 全队额外 +(等级 × 0.5%) |

按最低等级算。

## 14. 洗练与封存

区间目的：件有差别、能养成；不是肝满掷。

| 层 | 区间 | 洗 / 挪 |
|---|---|---|
| 底子 | 无 | 不洗 |
| 随机 | 有 | **每件锁定洗 1 行**（第一次选定后只能洗这一行）。类型 + 数值一起掷；保底行走副属性小池，全池行走全池 |
| 条件 | 有 | 可洗一行。另：封存 |
| 稀有 | 有 | 只能洗已有的稀有行，不能洗出「从无到有」 |
| T3 | 窄带 | 可换类型。不封存 |
| 孔 / 套 / 强化 | 无 | 不洗 |

**封存（昂贵，毁源件）：** 一条条件封成印。源件销毁（宝石退回，强化石不退）。印到另一件上覆盖指定那一条。

- 目标必须 **已经有条件**（紫金必有；蓝须自己掷出过）。  
- 槽位池匹配。  
- **同一破境档**（炼气印炼气）。不能印更高装等。  
- 极词仅金 → 金保留，印到紫 / 蓝压回普通上限。  
- 双条件：玩家指定封哪条、印上覆盖哪条。  
- 花费高于 T3 重铸。符与价格后填。

## 17. 战力

`战力 = 攻×a + 防×b + 抗×c + 血×d + 身法×e + Rating 折成% ×权重 + 各%词条×权重 + 战斗 T3 固定特效分`

装等 / 品级 / 强化已含在面板里，不另乘。条件每 1% 全额进。场外 T3、锁息、回元、气运特效分 0 或极低。穿不上的装不计。

角色 = 裸体面板加权 + 装备抬高的部分（`characterPower`）。队伍 = 上阵五人求和（`partyPower`）。建议战力按正在打的章展示（`chapter/bands.ts`），不锁进门。同战力错队仍可输（解法门）。权重见 `equipment/power.ts`。

## 19. 与战斗的接口

```
装备系统 derive（底子 ± 随机 ± 条件 ± 稀有 ± T3 ± 孔 ± 已激活套装 ± 形态石）
        ↓
   写入 UnitRuntime / 进战短 Buff
        ↓
战斗系统只按已有数值与 status 结算（不查 set 表）
```

判定：持盾 = 剩余护盾，格挡不算。对后排 = 目标当前行。相邻 = 上下左右。
