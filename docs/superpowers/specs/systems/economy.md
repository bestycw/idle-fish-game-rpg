## 10. 商业模式

| 阶段 | 策略 |
|------|------|
| V1 | 免费可玩；抽卡可用游戏内货币跑通；可接测试向付费实验 |
| 随后 | 真·抽卡付费（**新人 + 升星进度**）；月卡 / 体力续航 |
| 不做（原则） | 付费买通关权；章节硬锁逼氪 |

付费卖的是解法核流畅度；刷装风格核保持免费深度。见 [gacha.md](./gacha.md)、[build-dual-core-design](../2026-07-21-build-dual-core-design.md)。

Web 渠道获客预期：分享链接、社群、产品向社区；无小游戏级天然流量——接受并用产品体验换回流。
