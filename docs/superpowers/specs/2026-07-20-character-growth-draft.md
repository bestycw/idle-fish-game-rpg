# 人物成长与面板（工作草案 · 2026-07-20）

> **地位：** 工作假设，**非冻结**（不同于战斗 §4.14）。  
> 可改数值、层数、文案与后加轴；改结构时优先走本文「扩展口」，避免掀主循环。  
> 归属：[character.md](./systems/character.md) 成长子模块；爬塔薄壳已挂 [dungeon.md](./systems/dungeon.md)；抽卡碎片升星与 `followUp` 已接（B5 雏形）。

## 1. 目标（本阶段）

1. 人物有可读的成长三轴入口：等级 / 突破（境界）/ 升星  
2. 人物面板能展示属性与成长状态  
3. 结构预留扩展，后续加觉醒、好感、新货币不掀桌  

**本阶段不做：** 完整爬塔玩法深度、全卡独特星盘配满、技能独立升级树。  
**抽卡：** 规则见 [gacha.md](./systems/gacha.md)；实现仍服从战斗验收门禁，但成长上已约定「重复卡 → 升星 → 技能质变」。

## 2. 当前工作假设（可改）

### 2.1 三轴

| 轴 | 引擎概念 | 玩家可见（皮可换） | 当前假设效果 |
|----|----------|-------------------|--------------|
| 等级 | `level` | 等级 / 修炼层数 | 抬主四维底数（曲线后定） |
| 突破 | `breakthroughTier` | 境界（筑基/金丹…随词表） | **抬 `levelCap`** + 小幅属性跳点 |
| 升星 | `star` | 星级 ★ | 每星属性；**关键星解锁更强技能/被动**（解法质变，非纯加攻） |

> 升星在产品上属 **解法轨**（技能）+ 底子轨（属性）；重复卡来自抽卡。总图见 [build-dual-core-design](./2026-07-21-build-dual-core-design.md)。

### 2.2 资源三角（可扩）

| 货币 id（中性） | 当前主要用途 | 当前主要来源假设 |
|-----------------|--------------|------------------|
| `exp` | 升级 | 日常战斗 |
| `xiuwei` | 突破（境界） | **爬塔** |
| `stardust` | 升星（无重复卡时兜底） | 调试 → 抽卡碎屑/分解/活动（正式来源随抽卡） |
| （重复卡） | **升星优先消耗** | **抽卡主产出之一**；调试可发 |

可选：`gold`（灵石）仅作少量催化剂，**不能**单靠其拉满成长。

### 2.3 升星节点

- **共用阶梯**为默认（★1…★N 节点表）。  
- **特例卡**可在关键星挂独特节点（如赵云招牌能力）。  
- 叠法：默认 **`override`**（替换该星共用能力节点）；`stack: true` 时与共用叠加。  
- 属性层建议仍走共用，避免特例只强能力不强底子或相反难调。  
- 能力解锁优先挂已有战斗钩子：`followUp`、`effects`、`focusPolicy`、`applyStatus` 等，**不为升星新开战斗子系统**。

### 2.4 突破与皮

- 引擎只认 `breakthroughTier` 与 `levelCap`。  
- 「金丹」等名称只进 **skin 词表**，不进公式 id。

## 3. 扩展口（必须保留）

| 口子 | 要求 | 以后例子 |
|------|------|----------|
| `GrowthTrack` 注册 | 轴可增删；面板按注册表渲染入口 | `awaken` / `bond` |
| `CurrencyId` 开放字符串 | 新材料只加配置与来源 | 职能纹章、塔币 |
| `StarNode` 表 | 节点效果数据驱动；支持 override/stack | 新被动、新 followUp 参数 |
| `BreakthroughDisplay` 词表 | tier → 显示名随皮 | 武侠后天/先天 |
| `RewardSource` 标签 | 产出与消耗解耦 | `daily_battle` / `tower` / `gacha` / `debug` |
| 人物实例字段可空扩展 | `level`/`exp`/`breakthroughTier`/`star` 之外可加 | 好感度 |

**禁止写死：**

- 在战斗结算里写死「只有三种货币」的 switch 穷举且无法注册  
- 把「金丹」写进 core 公式 id  
- 升星解锁靠复制一整份战斗代码而不是钩子配置  

## 4. 与现有系统关系

| 系统 | 关系 |
|------|------|
| 战斗 | 只消费 derive 后的最终属性与已点亮的技能/钩子 |
| 装备 | 风格轨叠加；成长不替代刷装 |
| 抽卡 | 新人 + **重复卡喂升星**（技能质变）；规则见 [gacha.md](./systems/gacha.md) |
| 副本/爬塔 | 塔薄壳已落地：层数 → `xiuwei`；战斗化后置 |
| 道具背包 | 材料堆叠见 inventory-items；开工时从装备包拆出 |
