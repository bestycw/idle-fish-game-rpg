# 修为 / 境界养成（小节点 + 大破境）

> **地位：** 现行（2026-08-02 拍板）。  
> **原理：** 境界内小节点便宜、小加属性；破境节点贵、大加属性/上限。  
> **来源：** 修为 **只来自修炼塔**（不与抽卡/星尘抢）。

## 0. 产品位置

| 轨 | 货币 | 玩家在养什么 |
|----|------|----------------|
| 底子 | **修为**（塔） | 小节点属性 + 破境跳点 |
| 解法 | 碎片 / 星尘兑碎片 | 升星技能 |
| 软练级 | 经验（战斗本） | 等级（仍有 cap，不挡破境） |

## 1. 结构

```
炼气 ●─●─●─● ◆破境→ 筑基 ●─●─●─● ◆破境→ … → 化神
      小×4（修为）  大（修为多）
```

| 项 | 约定 |
|----|------|
| 每境小节点 | **4**（`CULTIVATION_NODES_PER_TIER`） |
| 小节点 | 花修为；主属性微幅累积（永久折算） |
| 破境 | 须 **小节点点满**；花更多修为；`breakthroughTier+1` + 破境被动；小节点进度归零 |
| 破境门闩 | **不再要求等级满 cap**（等级仍存在，经验本产；cap 仍限制升级） |
| 修为来源 | **仅** `climbTower`；猎装/镜渊/日常 **修为=0** |

## 2. 消耗初值

小节点（当前境第 n 个，n=0..3）：

`12 + tier×10 + n×5`

破境（离开当前境）：

`100 + tier×70`

（可调；原则：破境 ≈ 该境 4 个小节点总价的 1.2～1.5 倍级。）

## 3. 属性

- 已完成小节点总数 ≈ `tier × 4 + cultivationNodes`  
- 每点约 **主属性 +1.2%**（进 `deriveGrowthStats`）  
- 破境另享：原有 `tierBonus` + `breakthroughPerks`（大跳）

## 4. 塔产

保持层曲线，但修为是唯一产口；日摸鱼连爬会自然限速（体力若接塔再闸）。  
V1 塔仍可 instant；日后战斗化不改货币语义。

## 5. 代码

- 字段：`CharacterProgress.cultivationNodes`  
- `tryCultivateNode` / `tryBreakthrough`（改门闩）  
- GrowthTrack：`cultivate` + `breakthrough`  
- 实现备注见 `growth.ts` / `growthTracks.ts`

## 6. 不做

- 修为兑碎片 / 券  
- 多处产修为  
- 把升星并进境界盘
