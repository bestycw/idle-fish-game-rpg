# 修为 / 境界养成（小节点 + 大破境）

> **地位：** 现行（2026-08-02 拍板）。  
> **原理：** 境界内小节点便宜、小加属性；破境节点贵、大加属性/上限。  
> **来源：** 修为 **只来自修炼塔**（不与抽卡/星尘抢）。

## 0. 产品位置

| 轨 | 货币 | 玩家在养什么 |
|----|------|----------------|
| 底子 | **修为**（塔） | 小节点主属性 + 破境**肉身**（评级/稀有，按职能分轨） |
| 解法 | 碎片 / 星尘兑碎片 | 升星**招式**（斩杀/涅槃/招魂…） |
| 软练级 | 经验（战斗本） | 等级（仍有 cap，不挡破境） |

## 1. 结构

```
炼气 → 筑基 → 开光 → 辟谷 → 金丹 → 元婴 → 化神 → 炼虚 → 合体
→ 大乘 → 渡劫 → 散仙 → 地仙 → 天仙 → 金仙 → 太乙 → 大罗
每境 一层…十层 后破境
      小×10（修为）          大（修为多）

后续加境：只改 `packages/game-core/src/character/realmLadder.ts` 的 `REALM_LADDER`，往后 append。
已有下标是存档身份，不能插、不能换位。等级上限可省略（默认上一档 +8）。
装备穿戴仍是 5 档，化神起开最高装，后面加境不改穿戴。
```

| 项 | 约定 |
|----|------|
| 每境小节点 | **10**（`CULTIVATION_NODES_PER_TIER`） |
| 小节点 | 花修为；主属性微幅累积（永久折算） |
| 破境 | 须 **小节点点满**；花更多修为；`breakthroughTier+1` + 破境被动；小节点进度归零 |
| 破境门闩 | **不再要求等级满 cap**（等级仍存在，经验本产；cap 仍限制升级） |
| 修为来源 | **仅** `climbTower`；猎装/镜渊/日常 **修为=0** |

## 2. 消耗初值

小节点（当前境第 n 个，n=0..9）：

`12 + tier×10 + n×5`

破境（离开当前境）：

`100 + tier×70`

（可调；原则：破境 ≈ 该境 10 个小节点总价的 1.2～1.5 倍级。）

## 3. 属性

- 已完成小节点总数 ≈ `tier × 10 + cultivationNodes`  
- 每点约 **主属性 +1.2%**（进 `deriveGrowthStats`）  
- 破境另享：`tierBonus`（全员主属性+4%）+ **职能破境轨**（坦克坚韧/格挡，爆发暴击/穿透，治疗精通/气运…）
- 深做卡关键境用 `BREAKTHROUGH_OVERRIDES` **替换**该境职能行，不与职能行叠两条
- **禁止**破境再挂斩杀/连击/涅槃/招魂/禁咒——那些是升星的事

## 4. 塔产

保持层曲线，但修为是唯一产口；日摸鱼连爬会自然限速（体力若接塔再闸）。  
V1 塔仍可 instant；日后战斗化不改货币语义。

## 5. 代码
