# 技能系数带与 Debuff 命中（2026-08-03）

> 一人一主动下的数值可读与内容口径。实现以 `skills` / `deepKits` / `skillDisplayFor` / `combat.applyOneStatus` 为准。

## 1. 普攻与技能系数

- **普攻**系数固定 **1.0**，力系。
- 技能 `multiplier` = **相对普攻的系数**，不是固定伤害点。

## 2. 职责系数带（相对普攻=1）

| 职责 | 系数带 | 说明 |
|------|--------|------|
| 爆发/点杀 | 1.8～2.4 | 必须明显高于普攻 |
| 群体伤害 | 1.0～1.4 / 人 | 总伤可高于单体 |
| 硬控（晕/睡/混乱为主效果） | **1.05～1.35** | 底线不低于约 1.05 |
| 破甲/辅助低伤 | 0.9～1.2 | 可略低 |
| 治疗/护盾 | 独立灵系数 | UI 不与普攻对比 |

## 3. Debuff：必中铺垫 vs 概率硬控

**意图：** 不确定性 + 精通/词缀有价值 + 克制关大显身手。

| 类型 | 例 | 命中 | UI |
|------|----|------|-----|
| **铺垫（破阵）** | 破甲、流血、迟缓、禁疗、猎印 | **必中**（逻辑上不掷抵抗；**文案不写「必中」**） | `附加破甲2回（防御×82%）` |
| **硬控** | 眩晕 / 沉默 | 命中率，`landBase` **40%** +精通−幸运 | `附加眩晕1回 · 命中率40%` |
| **强扰乱** | 混乱 / 狂乱 / 沉眠 | 更低：`landBase` **25% / 25% / 30%** | `附加混乱1回 · 命中率25%` |
| **己方 Buff** | 治疗 / 护盾 | 必中 | 不写命中句 |
| **己方资源触发** | 灌气赌博 | 自己掷骰，**不吃精通/幸运** | `25% 灌气 56`（写触发，不写命中） |

仍可有配置层 `chance`（如星章 70%附加猎印）：先掷触发，触发后铺垫仍必中。  
`effects[]` 触发率见 [效果触发率](./2026-08-30-effect-proc-chance-design.md)。治疗/护盾仍必中。  
精英/Boss：`rankGate` 可免疫/减半（与命中无关）。

## 4. 精通（不止命中）

对齐 `combat.md` §4.12.3，已落地扩展：

| role | 精通收益 |
|------|----------|
| st_ctrl / aoe_ctrl | **命中** +m；**控/扰乱时长** ×(1+m×0.15) |
| flex | 命中 +m×0.35；时长半额；破甲/猎印微强化 |
| group_amp | **破甲更深**（防乘区更低）；**猎印承伤**略增 |
| tank / heal / burst / aoe_dps | 仍以伤/盾/疗/穿为主（既有） |

装备「精通」词缀进入 `masteryRating`，技能页强度与命中率会跟着变。

## 5. 技能页可读

- `伤害 = 力系×1.15`
- 铺垫：`附加破甲2回（防御×82%）`（不写必中）
- 流血/毒/灼：`附加流血3回（每回生命上限3%）`（目标最大生命 × 3% × 层数，每动跳一次）
- 硬控：`附加眩晕1回 · 命中率40%`
- 强扰乱：`附加混乱1回 · 命中率25%`
- **命中率 ≠ 效果强度**（强度在括号里）
- **点词开小弹窗：** 技能行/星章/属性上的「流血」「暴击」等可点，弹出该词短注，底下可切同类。不是手册页。
