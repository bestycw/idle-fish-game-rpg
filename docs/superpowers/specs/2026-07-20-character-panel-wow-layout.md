# 人物面板布局（2026-07-20 · 2026-08-23 对齐现网）

> **地位：** 现行 UI 布局规格。成长数值认 [character.md](./systems/character.md)；槽位与穿戴认 [equipment.md](./systems/equipment.md)。  
> 旧稿「左右槽列 + 底下升级/破境/升星」已废，勿按那套实现。

## 1. 目标

1. 人物详情四页签并列：**属性 · 境界 · 技能 · 装备**。  
2. 装备页一次露出完整 **12 槽**：上 6 / 中属性 / 下 6。  
3. 养成入口拆开：升级在属性页；修炼/破境在境界页；升星与兑碎片在技能页。

## 2. 已拍板决策

| 项 | 决定 |
|----|------|
| 页签 | 属性 / 境界 / 技能 / 装备 |
| 装备骨架 | **上 6 格 → 中属性牌 → 下 6 格**（不是左右槽列） |
| 属性页 | 只留**升级** |
| 境界页 | `RealmMeridian`：左境名 + 右十层法盘 + 底下一颗修炼/破境 |
| 技能页 | `SkillManual`：功法卷 + 星章轨 + 升星 + 兑 |
| 槽位露出 | **12 槽全开**（`EQUIP_SLOTS`） |
| 装备归属 | **每角色独立装备栏**（`characterEquip`） |
| 加工 | 强化 / 镶石 / 重铸 / 继承 / 分解 / 洗练 / 封存 **只进行囊** |
| 入口 | 布阵点角色 + 顶栏「人物」列表 → 详情 |

## 3. 装备页（上 → 下）

```
┌─────────────────────────────────────┐
│  [返回]          属性·境界·技能·装备   │
│  [头][链][胸][手][裤][鞋]             │
│  ┌─────────────────────────────┐    │
│  │ 中核 · 属性条（主/副/稀有）     │    │
│  └─────────────────────────────┘    │
│  [戒①][戒②][武][副][饰①][饰②]       │
│  更换栏（同槽背包 · 6 列）            │
└─────────────────────────────────────┘
```

### 3.1 槽位摆放

| 位置 | 槽 id |
|------|--------|
| 上排 | `head` `neck` `chest` `hands` `legs` `feet` |
| 下排 | `ring1` `ring2` `weapon` `offhand` `trinket1` `trinket2` |

空槽 `+` 要大。选中槽位绕格琥珀虚线。

### 3.2 中核 · 属性条

展示穿上当前栏后的主 / 副 / 稀有。点格子弹属性窗，锚在点中的格子上。  
中核不放立绘、不放雷达图。

### 3.3 更换栏

点槽打开同槽背包（`grid-cols-6`）。点空槽**只开更换栏**，不要自动弹出第一件。  
卸下允许清空该槽，件回公共库存。

## 4. 交互

| 操作 | 行为 |
|------|------|
| 点空槽 | 打开更换栏；不自动穿第一件 |
| 点已装槽 | 属性弹窗锚在格子上；更换栏列出同槽候选 |
| 加工 | 行囊格子弹窗；不进槽位弹窗 |
| 卸下 | 清空该角色该槽 |

窄屏同一骨架，不必改回左右槽列。

## 5. 非目标

- 槽位随章节灰锁  
- 中核立绘 / 3D  
- 共享衣柜  
- 把升星按钮放回属性页  
- 把加工塞回槽位弹窗  

## 6. 验收

1. 详情页四页签可用；装备页可见 12 个槽。  
2. 空槽大 `+`；选中琥珀虚线。  
3. 点空槽只开更换栏。  
4. 升级 / 破境 / 升星分别在属性 / 境界 / 技能页。
