> 本文件冻结的是**面板骨架与槽位露出**，避免实现时来回改结构。

## 1. 目标

1. 人物详情页呈现「魔兽式纸娃娃」：装备槽环绕、中核属性饱满、下方养成。  
2. 一次露出完整 **16 装备槽**（与装备规格全集对齐）。  
3. 与现有双通道入口、三轴养成、共用衣柜兼容。

### 3.1 槽位摆放（对齐魔兽去外观）

| 位置 | 槽 id（顺序建议） |
|------|-------------------|
| 左列（上→下） | `head` `neck` `shoulder` `back` `chest` `wrist` `hands` `waist` |
| 右列（上→下） | `legs` `feet` `finger1` `finger2` `trinket1` `trinket2`（不足则空位占位，勿塞无关槽） |
| 底栏 | `mainHand` `offHand` |

> 右列仅 6 个真实槽时，可用空格或弱化占位保持列高与左列视觉平衡，**不新增第 17 槽**。

### 3.2 中核 · 四维卡片墙（A）

自上而下：

1. **境界徽章**（`breakthroughLabel`）  
2. **角色名**（英雄可带 ★ 前缀）  
3. **副标题一行：** role / job 或技能特长 · `Lv level/cap`  
4. **星级排**（★ 点亮，上限与成长表一致，当前展示建议 5）  
5. **主属性墙：** 攻击 / 灵力 / 防御 / 灵防 / 生命 / 身法（力·灵双轴已落地）  
6. **副属性墙（全露出）：** 暴击 / 暴伤 / 急速 / **均衡** / 精通 / 终伤 —— 展示 **% + 评级**  
7. **稀有 / 特殊墙（全露出，含 0）：** 幸运、闪避、吸血、抗暴、格挡 —— 有值实线，无值虚线弱化  

> 2026-07-21：中核由四维摘要改为双轴主墙 + 副属性/稀有全墙。

中核不放立绘、不放雷达图、不放三轴进度条（进度在下方按钮上）。

### 3.3 下方养成

- 三钮：升级 / 破境 / 升星（逻辑沿用 `tryLevelUp` / `tryBreakthrough` / `tryStarUp`）。  
- 钮上展示消耗与进度条。  
- 其下：技能名与耗能；已解锁升星节点列表；下一星预览。

## 4. 交互（本切片）

| 操作 | 行为 |
|------|------|
| 点空槽 / 已装槽 | 可从背包**同 `slot`** 装备中挑选穿戴（调用现有 `wearLoot` / `equipItem`）；无候选时提示 |
| 侧栏背包 | 保留；与槽内换装并存 |
| 卸下 | 本切片可不做完整卸下；若易加则允许清空该槽 |

窄屏：左右槽列可改为「上：中核；中：槽位两列网格；下：养成」，但桌面优先纸娃娃。  
**布局（2026-07-21）：** 纸娃娃区 `max-w-md` 居中；左右槽 `items-stretch` 与中核同高均分；中核收紧字号与内边距。
