# 深做卡功能钩子（不是零件叠加）

> **地位：** 现行切片。把已深做卡从「词缀拼盘」补成「一人一条功能」。  
> **拍板：** 2026-08-30。  
> **配合：** [legendary-signature-kit](./2026-08-29-legendary-signature-kit-design.md)、[effect-proc-chance](./2026-08-30-effect-proc-chance-design.md)、[skill-design-spec](./2026-08-02-skill-design-spec.md)。

---

## 0. 问题与目标

技能栏只有一招时，若全是「伤害×系数 + 解锁零件」，打起来同质。网游/网文有意思的是 **场合换招、资源赌博、标记咬合、残局质变**，不是数值叠层。

**目标：** 现有深做卡每人 ★0 有一条能讲清的功能钩子；升星加深这条，不另开技能栏。

**非目标：** 不扫 200 卡；不加姿态/连击点系统；不新开状态主表 id；治疗/护盾底盘仍必中。

---

## 1. 功能类型（只用现网引擎）

| 类型 | 接法 |
|------|------|
| 条件变招 | `softModes`（现成 when） |
| 资源赌博 | `SkillEffect.chance`（写触发，不写命中） |
| 标记咬合 | 已有状态 + `target_has_status` |
| 残局/先声 | `self_hp_below` / `first_cast` / `target_hp_below` / `ally_downed` |
| 节奏剥夺 | 抽气/沉默/迟滞；可加触发或变招 |

不做：新 when 种类、新状态 id、人人都改成 25% 灌气。

## 3. 验收

- 上述卡 ★0 技能页能看见变招句或 `25% 灌气`。  
- 遮名仍能猜人（勿做成第二张刘备）。  
- 治疗/护盾未改成概率。  
- 未改卡的灌气仍必中。
