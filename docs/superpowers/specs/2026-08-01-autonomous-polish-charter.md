# 自治完善约定（Agent Loop）

> **地位：** 工作约定（2026-08-01）。  
> **核心玩法不变：** 九宫布阵 × 刷装构筑；双核（人解法 / 装风格）；策略可过关、付费买流畅。

## 1. 授权范围

Agent 可在不打断用户的前提下循环：

1. 按规格完善：**战斗手感与数值**、**角色能力/数量/技能池**、**装备数值与词条池**等  
2. 用数据日志自测 → 分析 → 调参 → 再测  
3. 参考主流（仙剑新的开始 / 再刷一把 / 魔兽 / 文字养成）只借一层，禁止摊成四不像  
4. **发生变动必须写入** [balance-changelog.md](./balance-changelog.md)

## 2. 硬限制

| 禁止 | 说明 |
|------|------|
| **自行 git commit / push** | 由用户决定何时提交 |
| 改战斗主循环乱 if | 新效果走 register* / 配置表 |
| 另开第三条养成主轴 | 新内容须归属「人」或「装」 |
| 有版权 IP | 卡面仅公版 |

## 3. 推荐循环顺序（可穿插）

```
战斗手感基线脚本 → 调遭遇/技能/成长曲线
     ↓
技能池 & 升星特例加深（仍走现有钩子）
     ↓
卡池内容（向 16–24，公版）
     ↓
装备词条池 / 稀有档 /（套装 2/4 仍可后置但口子要对）
     ↓
章节遭遇与掉落对齐双核
```

## 4. 自测最低标准

- `game-core` 单测保持绿  
- 手感脚本：默认开局队 vs `wall` / `archers` / `raiders` 多 seed 摘要（胜率、回合、战败提示）  
- 大改后在 changelog 记「基线前后对比」一两句  

## 5. 汇报格式（每轮结束）

- 本轮改了什么（指向 changelog）  
- 基线数据摘要  
- 下一步打算  
- **提醒用户自行 commit**（Agent 不提交）
