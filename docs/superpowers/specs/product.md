## 1. 背景与目标

### 1.1 为什么做

在 AI 时代，以个人开发者副业形式，打造**可复利的产品资产**（而非纯接单换时间）。

### 1.2 约束

| 项 | 结论 |
|----|------|
| 时间 | 每周约 5–10 小时 |
| 能力 | 全栈，可独立交付可用 Web 产品 |
| 目标 | 可复利资产（引擎可复用、内容可迭代、付费可长线） |
| 用户 | 上班族；利用碎片时间「摸鱼」游玩 |

### 1.3 成功标准（阶段性）

**V1（可玩验证）**

1. 陌生人能在 **10–20 分钟**内完成一段有收获的会话（战斗 / 刷装 / 抽卡至少体验其一，理想三者都沾到）。
2. 核心循环可重复：「布阵过关 → 刷装 → 抽卡改阵 → 再推进」。
3. 不氪金玩家可多试、靠策略通关；付费只提升流畅度（**抽卡进度 / 升星速度** / 后续体力续航），不买通关权。
4. 引擎与内容皮肤分离，官方占位剧情可整包替换。

**更长期**

- 有稳定回流（每天少量主动游玩，非挂机）。
- 付费点跑通（先抽卡，后月卡/体力）。
- V2：有限剧情个性化提升粘性与传播。

## 2. 产品定义

### 2.0 可玩性基调（已拍板 · 2026-07-21；定位分层修订 2026-08-07）

> **一句话身份（对外）：** 上班也能开的 **文字策略养成**——九宫布阵 × 刷装构筑，过关靠**搭配与解法**；故事外皮可由 AI 换皮。  
> **短 slogan：** `布阵刷装 · 摸鱼深构筑`（**不写**「十分钟」）。  
> 修订全文见 [positioning-revision](./2026-08-07-positioning-revision-design.md)。

**三层分工（防跑偏）：**

| 层 | 是什么 | 不是什么 |
|----|--------|----------|
| **入口（摸鱼）** | 场景标签：上班能开、战中低操作、不绑挂机 | 品类深度承诺；「随便玩玩」 |
| **本体（深度）** | 人·解法 + 装·风格双核；多策略刷装配阵 | 战力墙 / 挂机收菜 / 特效主循环 |
| **外皮（AI）** | 世界观/文案/包装可换 | AI 生成数值/技能当主玩法 |

**玩家应稳定感到：**

1. **选择多：** 换人、换站位、换装、调流派（含力/灵双轴），同一关常有多条活路。  
2. **刷有意义：** 掉落能改变「怎么打」，而不只是数字变大。  
3. **阵容有意义：** 缺解法位就难受；抽卡/升星补的是「会什么」，不是纯面板。  
4. **可短开、可深玩：** 一会话能打完/重搭/感到进步（内部验 10–20 分钟）；构筑深度长期叠。

**丰富性只走两条主梁（双核），禁止摊成四不像：**

| 主梁 | 负责 | 做到什么程度算够 |
|------|------|------------------|
| **人 · 解法** | 卡池职能、技能、布阵、升星技能质变 | 换阵/换人能翻盘 |
| **装 · 风格** | 词缀分层、套装、T3、T4 | 换装能改打法与对症 |

其它系统（抽卡、章节、体力、故事皮）都是**服务双核或节奏**，不得另开第三条「也能通关但互不相干」的养成主轴。

**反四不像守则（设计时逐条过）：**

| # | 守则 |
|---|------|
| 1 | **先问归属：** 新系统是加强「人」还是「装」？两边都不沾 → 默认不做或极后置。 |
| 2 | **一条身份：** 对外先钉「布阵刷装策略养成」；摸鱼只作入口；不宣称自己既是完整魔兽、又是完整再刷一把、又是完整仙剑。 |
| 3 | **参考只借一层：** 仙剑→九宫与软关；再刷一把→刷装与特技思路；魔兽→副属性/纸娃娃。**禁止三套主属性体系并行**（结果层双轴 + 副属性即可；力耐敏智只能作后置转化）。 |
| 4 | **深度用正交，不用堆系统：** 宁可 2 核凿深，不要 8 个半吊子系统。 |
| 5 | **过关检验：** 若玩家只能靠「肝等级/氪战力」过关，而不是换搭配——基调失败，需改关卡或提示，而不是再加养成轨。 |
| 6 | **摸鱼/AI 自检：** 是加深「怎么过关」的选法，还是只加「摸鱼感 / AI 花活」？后者默认不做。 |

总图与细则：[build-dual-core-design](./2026-07-21-build-dual-core-design.md)。

### 2.1 一句话（展开）

> **Web 文字策略养成 RPG**（上班也能开）：  
> 以**随机装备 + 抽卡定核 + 九宫布阵（自动战斗）**推进章节与副本；  
> **可玩性基调见 §2.0**（双核丰富、非硬战力、非四不像）；  
> **主动玩、不挂机**（会话时长是内部节奏，不写进对外主身份）；  
> **故事外皮可 AI / 玩家换皮**（或官方默认皮）；  
> **卡池跨题材**（公版神话/名著/历史或原创），战斗只认职能定位。

### 2.2 参考与边界

| 参考 | 借鉴 | 不借鉴 |
|------|------|--------|
| 《再刷一把 PlayAgain》 | 养成、抽卡、刷装、阵容、爬塔；**词条/特技改打法**的思路 | Steam 买断形态；过重系统（宠物/完整符文库等）；照搬连击再动模型 |
| 《仙剑奇侠传：新的开始》 | 章节节奏、**九宫布阵**、自动索敌、软难度可过关、主角可操作感 | 任何仙剑 IP；硬卡池逼氪；重度经营 |
| 文字/养成摸鱼产品 | 短会话、低操作战中 | 挂机收菜主循环、纯数值墙 |

### 2.3 故事皮 × 卡池皮（已确定 · 修订）

> **不必锁定仙侠。** 剧情若以「玩家提供设定 + AI 在框架内生成」为主路径，故事题材应是皮肤，不是产品宪法。

| 层 | 内容 |
|----|------|
| **故事皮** | **完全可换**：玩家开局给世界观/基调（或选官方默认皮）→ AI 按**固定章节骨架**生成文案与包装；也可全程默认皮、不生成 |
| **官方默认皮** | V1 可用**中性占位**或任一短默认线（可为仙侠，**不是强制**）；只为「不想写设定」的用户服务 |
| **卡池角色** | 与故事题材**解耦**。关羽、孙悟空等公版形象或原创均可；进战斗只看 **role + 技能** |
| **自洽** | 由当前故事皮解释「为什么这些人一起打」（英灵、梦境、剧本杀、平行招聘…）——生成层解决，不写死引擎 |
| **主角** | **全能**；显示名/来历随故事皮或玩家设定，职能不变 |
| **属性/技能显示名** | **随故事皮变**；引擎 id 不变（见 §2.3.1） |

#### 2.3.1 文案皮肤：属性名 / 技能名（已确定）

> 不同背景（仙侠 / 神魔 / 魔幻 / 科幻…）不应共用「周天」「真元」等强题材词当**唯一**玩家可见名。  
> 做法与卡面皮相同：**逻辑名固定，显示名查表**。

| 层 | 规则 |
|----|------|
| **引擎字段** | 固定英文/内部 id：如 `versRating` `hasteRating` `qi` `critRating` `masteryRating`… |
| **默认显示名（中性）** | 无故事皮或占位皮时用中性词。例：vers→**均衡**（勿用「全能」，以免与职能「全能」撞名），haste→**急速**，qi→**能量**，crit→**暴击**，mastery→**精通**，finalDmg→**终伤**，fortune→**幸运**，spd→**速度** |
| **故事皮词表** | 每个 `skinId`（或 AI 生成缓存）可带 `statLabels` / `resourceLabel` / **`jobLabels`** / 状态短名映射；仙侠皮才用「周天 / 神速 / 真元 / 会心 / 气运」 |
| **技能名 / 战报动词** | 同样可映射；`skillId` 与结算不变 |
| **职业显示名** | `jobId` 固定；UI 用 `t(jobId)`。例：中性「刺客」↔ 仙侠「影刺」↔ 科幻「渗透者」——**不得把题材专名写进引擎** |
| **AI 生成** | 允许生成词表，但**不得改字段 id 与公式**；缺词时回退中性默认 |
| **UI** | 所有玩家可见属性字符串走 `t(statId)`，禁止在组件里写死「周天」 |

**示例（同一字段，不同皮）：**

| 字段 | 中性默认 | 仙侠皮 | 魔幻皮 | 科幻皮 |
|------|----------|--------|--------|--------|
| hasteRating | 急速 | 神速 | 迅捷 | 超频 |
| physAtk | 攻击 | 武力 | 力量 | 动能 |
| spiritAtk | 灵力 | 灵力 | 智力/法强 | 算力 |
| physDef | 防御 | 护体 | 护甲 | 装甲 |
| spiritDef | 灵防 | 御灵 | 魔抗 | 干扰屏蔽 |
| versRating | 均衡 | 周天 | 调和 | 自适应 |
| qi | 能量 | 真元 | 法力 | 能量槽 |
| fortune | 幸运 | 气运 | 气运/天命 | 概率修正 |
| shred | 破甲 | 裂甲 | 破防 | 护盾干扰 |
| job:assassin | 刺客 | 影刺 | 刺客 | 渗透者 |
| job:mage | 法师 | 法修 | 法师 | 能源术士 |
| job:healer | 治疗 | 丹医 | 牧师 | 医疗官 |

**规格正文约定：** 属性叙述优先用 **`字段id` + 中性名**（如 `hasteRating`/急速）。括号内可附题材例（仙侠：神速）。实现与 UI 以 id + 词表为准。

### 2.4 市场判断

- 差异化靠：九宫布阵可翻盘、词缀刷装、**可换故事皮 + 跨题材卡池**、非挂机碎片体验。  
- 宣传避免绑死「又一个修仙挂机」；修仙只是可选默认皮之一。

### 2.5 版权

- 不可使用仙剑等**受版权保护的游戏/影视 IP**。  
- **公版**神话名著历史形象可用；避免影视/游戏独特造型与商标台词。  
- AI 生成须落在框架内，并做基础安全/版权规避（后置细则）。

## 6. 用户体验：上班摸鱼（入口层）

### 6.1 定位话术（已拍板 · 2026-08-07）

> **对外：** 布阵刷装 · 摸鱼深构筑——文字策略养成，过关靠搭配；外皮可 AI 换皮。  
> **对内节奏（不进 slogan）：** 一会话约 10–20 分钟有收获；可拆多段。

### 6.2 体验要求

| 要求 | 说明 |
|------|------|
| 打开即续玩 | 尽快回到战斗/副本，减少菜单迷宫 |
| 随时可停 | 单场短；领导经过可快速切走 |
| 界面克制 | 偏文字/工具感，少闪爆全屏动画（沉浸在构筑与战报） |
| 静音默认 | 办公室友好 |
| 进度稳 | 本地存档；可选后续云存档 |
| 一会话有收获 | **内部指标：** 10–20 分钟内打完 1–2 场或刷 1 趟本并看到掉落 |
| 战中低操作 | 默认全自动；策略在布阵与养成；可选动手动主角 |

### 6.3 与挂机的区别

- 挂机：上线收菜、离线也涨。
- 本产品：必须主动**布阵**（及可选的主角手动）；战斗过程可自动，但不是离线挂机涨战力；离线不推进核心玩法进度（体力自然恢复除外）。

## 8. V1 内容量规格（已认可方向）

| 模块 | 规格 |
|------|------|
| 主线 | 6–8 章；每章 3–5 场战斗 + **可换皮短剧情**（默认占位 / 后接 AI） |
| 角色池 | 16–24 张卡（含 3–4 高稀有）+ **固定全能主角**；卡面跨题材，**职能盖全 9 类** |

| 装备 | 见 [equipment.md](./systems/equipment.md)（12 槽、每角色独立）；面板见 [character-panel-wow-layout](./2026-07-20-character-panel-wow-layout.md) |
| 副本 | 2 种 |
| 抽卡 | 1 常驻池 + 保底；职能加权；**重复卡喂升星（技能质变）**；见 [gacha.md](./systems/gacha.md) |
| 体力 | 支撑每日 10–20 分钟 × 2–3 段 |
| 付费 | 先抽卡；月卡/体力预留 |
| 剧情 | 题材不锁定；占位默认皮 +（V1.5/V2）玩家设定/AI；与卡面来历可不同源 |
| 策略 | **双核：** 刷装调风格 + 抽卡/升星补解法与技能质变 + 布阵翻盘；总图见 [build-dual-core-design](./2026-07-21-build-dual-core-design.md) |
